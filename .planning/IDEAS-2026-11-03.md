## 1. Tool MCP `orrery` cho Claude / Codex (apps/desktop/src/pty/mcp.ts, hiện chỉ `open_session`)
- `run_app` / `run_status` / `run_log(lines)`: chạy config Run của project pane, trạng thái, N dòng lỗi cuối (ngược với sendErrorToAgent).
- `device_screenshot(serial?)`: chụp máy qua adb (devices/), trả đường dẫn PNG trong thư mục chụp của project.
- `preview_layout(path, device?)`: render XML qua layout daemon → PNG (chỉ khi daemon đã warm hoặc gọi = tín hiệu warm; memory no-always-on-jvm).
- `open_in_workspace(path, line? | diff?)`: mở viewer/diff trong pane cho chủ nhân xem.
- `notify_owner(text, level)`: Inbox + toast + điện thoại theo setting thông báo (rate limit).
- `who_is_editing(path)`: agent khác đang sửa file này? (dữ liệu OverlapChip).
- `list_servers` / `free_port(port)`: xem cổng / server bỏ quên; dừng qua confirm native.
- Gắn MCP cho pane Codex (`mcp_servers` trong config.toml) nếu Codex 0.162 hỗ trợ — kiểm bản cài trước, ghi docs/codex-integration.md.
