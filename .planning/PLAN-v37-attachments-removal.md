# v37 — Attachments removal (Backspace + any order)

Full plan: `docs/superpowers/plans/2026-10-15-attachments-removal.md`. Audit: `.planning/AUDIT-2026-10-15-pending-plans.md` (attachments-removal).

- **Goal:** the pane's Attachments tray follows Backspace in the prompt, and × removes any item, not only the last.
- **Ghost-row cause:** each Backspace on `@package.json` left `@package.jso`, `@package.js`… which the scan added as new "terminal" rows. Fix: `cursorToken` names the mention ending at the cursor; `attachments.reconcile(…, editing)` gives it no row until a space follows.
- **`eraseKeys`** (replaces `eraseCount`): ← to just after the token (+ its space), Backspaces (1 per `[Image #N]`, 1 per mention char, + space), → back.
- **Shared queue:** inserts and erases go through one `enqueue` chain in `usePaneAttachments` (`pending` count), each erase from a fresh screen read after everything before it finished; one key per write (12 ms gap), ESC O D/C when xterm `applicationCursorKeysMode`. `idle()` gates tray inserts and TermPane's `insertRequest` watcher so a paste never lands between erase keys. A × clicked while something is queued skips the pre-check (screen mid-change); the queued erase checks a settled screen.
- **Closed-loop erase (`eraseNow`):** ← burst, then `caretTo` reads the caret back and nudges until it sits right after the token; `eraseKeys` re-checked (left 0, same Backspace count) before any Backspace; → back; counts the removal only when the redrawn prompt holds one token fewer (`tokenCount`), else the tray shows "remove it in the terminal".
- **Caret (`promptCaret`):** an Ink app may hide the cursor and draw the caret as one inverse-video cell: take the single inverse cell inside the input box (cursor must agree if also inside), else the cursor if inside the box, else unsure → type nothing. On Claude Code 2.1.294 the cursor sits on the caret; the inverse path is the fallback.
- **`NARROW` whitelist:** the row before the cursor must hold only one-cell, one-UTF-16-unit characters (ASCII, Latin incl. precomposed Vietnamese, Greek, Cyrillic, punctuation, arrows, box drawing, `❯`) so a cell equals a string index; anything else (CJK, emoji, zero-width, combining) → no erase.
- **`@file:line[:col]`** (Run pane "Send to agent", `lib/runUi.ts` `errorPrompt`, also quoted `@"a b.dart":12:5`) is a place, not an attachment: `scanPrompt` skips it (owner decision 2026-10-15).
- **Rulings:** (1) ghost rows are the Backspace bug; (2) removal moves the cursor with arrow keys, only on the user's click, never Enter; (3) tokens on another row / after the cursor / with wide chars before the cursor keep the "remove it in the terminal" notice (reworded); (4) one key per write, 12 ms gap, `ESC [ D` or `ESC O D`.
- **Tests:** `lib/promptAttachments.test.ts`, `stores/attachments.test.ts`, `composables/usePaneAttachments.test.ts`; E2E `apps/desktop/e2e/v25.cjs` (Backspace, any-order removal, no ghost rows) **PASS** on a real Claude Code 2.1.294 pane (Windows 11, 2026-10-15). Docs §11p item 4.
- No app version bump (bumped once for the whole batch).
