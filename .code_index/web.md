# web — apps/web (Vue 3 + Vite + Tailwind v4 + Pinia + vue-i18n + Vue Flow)

Paths are relative to `apps/web/src`. Plans: `.planning/PLAN-v*.md` (version tags below point there). History of changes: `_meta.md`.

Flow: `stores/connection.ts` (WebSocket `/ws`, seq check, resync, backoff 1→10 s) → `apply()` → domain stores → components.

Invariants:
- No horizontal scroll: grid children `min-w-0` + `grid-cols-[minmax(0,1fr)]`; the map pans inside its canvas.
- Agent Map positions are recomputed only on structure change; nodes hold only the agent id and update incrementally.
- Status = icon + text + colour (`lib/status.ts`, `StatusIcon`, `StatusBadge`); colours only via tokens (`.planning/COLOR-SYSTEM.md`).
- `lib/layout.ts` = Agent Map layout; `lib/splitLayout.ts` = Workspace split tree. Unrelated.
- Every user string via i18n (en + vi, `i18n/messages.test.ts` compiles every message; a bare `@` breaks vue-i18n, escape as `{'@'}`).

Reveal object dropped when done; without `warmUp` (timelapse rebuild, tests) every path is the old one.
