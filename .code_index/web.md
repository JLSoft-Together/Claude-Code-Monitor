# web — apps/web (Vue 3 + Vite + Tailwind v4 + Pinia + vue-i18n + Vue Flow)

Flow: `stores/connection.ts` (WebSocket /ws, seq check, resync, backoff 1→10s) → `apply()` → terminals / agents / activity stores → components.

- Views: `App.vue` → `AppHeader` (tablist Monitor/Usage, sliding pill, theme via View Transition) + `<Transition name=ccm-view>` → `MonitorView` (`MetricsStrip` tiles + sessions/map/activity grid) | `usage/UsageView` (filters range/metric/model/project, scan progress, `UsageKpis`, `UsageDailyChart` (SVG stacked bars, hover/keyboard tooltip, table toggle, legend toggles series), `UsageModels` (table + bars, click = filter), `UsageProjects` (top 8 + other), `UsageLive`).
- `stores/usage.ts`: buckets by key, `range`/`metric`/`hidden` persisted `ccm.usage`, `modelSlot` (color by sorted model name, not rank), `daily`/`byModel`/`byProject`/`totals` (cost via shared `estimateCost`, `unpriced`). Cache read hidden by default.
- `lib/title.ts` `displayTitle` (alias > registry name) used by SessionCard/AgentNode/AgentDetails/ActivityFeed/UsageLive; `isAutoNamed`. Rename inline in `SessionCardHeader` → `connection.setAlias`.
- SessionCard split: `SessionCard.vue` (layout, note, status/snooze, chips, diff, cwd, footer) → `SessionCardHeader.vue` (title row buttons, rename form, jump/open errors, name hints; emits `note`) + `SessionCardSignals.vue` (quiet/cache/loop/conflict lines). Alias + note forms share `composables/useInlineEdit.ts` (`start(initial, select)`, `commit(save → bool)`, `cancel`).
- Motion: `style.css` keyframes `ccm-pop` (node mount), `ccm-flash` (status change), `ccm-breathe` (working node), `ccm-grow`/`ccm-grow-x` (bars), `ccm-highlight` (new activity), list/view transitions, hot edge dash flow; all off under reduced motion. `composables/useCountUp.ts` for KPI numbers.
- Stores: `terminals.ts` (byId, list stable order live→startedAt, patch null=delete), `agents.ts` (byTerminal, mainOf, lineage for highlight), `activity.ts` (newest first, cap 300), `settings.ts` (theme/locale → localStorage `ccm.theme`/`ccm.locale`, html class/lang), `ui.ts` (view, `collapsed` panels persisted `ccm.collapsed` + `togglePanel`, selectedAgentId, focusTerminal → focusRequest, resetLayout).
- `lib/`: `format.ts` (global `now` 1s clock, relativeTime, duration, compactNumber en-US), `status.ts` (status → glyph + i18n key + literal Tailwind classes), `layout.ts` (`computeLayout` grid-wrapped trees, `treeOrder` DFS by parentId with indent capped at depth 2, `visibleAgents` hide completed/cancelled subagents but keep ancestors of visible ones, `columnsFor(width)`), `patch.ts`.
- Components: `AppHeader` (connection, theme/lang toggles, stale banner) → `MetricsStrip`; `SessionList` → `SessionCard` (click = focus map); `AgentMap` (Vue Flow, hide-finished toggle from `settings.hideFinished`, nodes hold only agentId, incremental add/remove/updateNode, fit on `nodesInitialized`) → `AgentNode` (reads store, lineage dim via inject `ccm-highlight`), `AgentDetails`; `ActivityFeed`; `StatusIcon` (signature: Claude ✳ spinner glyph set).
- Theme tokens: `src/style.css` CSS vars `--ccm-*` (light :root, dark .dark) mapped in `@theme`; cool graphite + cobalt accent; status working=orange, waiting=amber. Chart slots `--ccm-cat-1..8` (dataviz palette, validated light+dark) → `series-input/output/write/read`. Type scale bumped (2xs 12, xs 13, sm 15). Never hex in components.
- i18n: `src/i18n/{en,vi}.ts` (vi typed against en). Activity keys `activity.<kind with _>`; unknown kind → raw kind.
- Index.html inline script sets theme before paint.
- Tests: `src/stores/stores.test.ts` (snapshot/patch/seq gap/activity cap/layout overlap).
Invariants: grid children `min-w-0` + `grid-cols-[minmax(0,1fr)]` (no horizontal scroll); map positions recomputed only on structure change.
- Collapsible panels: `PanelHeader.vue` (h2 > button aria-expanded, chevron) used by `SessionList` (rail from lg) and `ActivityFeed` (rail from xl); collapsed = body `v-show` hidden, `MonitorView.gridClass` swaps literal grid-template classes (48px rail / auto row), grid template transitions 200ms.
- Sprint A web:
  - `composables/useNotifications.ts` (installed in App): `transitionKind` (any→waiting = waiting, working→idle = done), desktop Notification only when tab hidden/unfocused, 30 s throttle per terminal+kind, click → focus session; tab title `(N)` waiting count.
  - `stores/settings.ts`: `palette` ember (default, old warm palette) | cobalt → `html[data-palette]` (set pre-paint in index.html, tokens in style.css `:root:not(.dark)[data-palette=ember]` / `.dark[data-palette=ember]`); notify flags `ccm.notify*`, `toggleNotifications` requests permission on click.
  - `SettingsMenu.vue` (bell + gear popover) in AppHeader. `ContextGauge.vue` (scaleX bar, icon+text per level) in SessionCard + AgentNode (node heights MAIN 150 / ROW 128). `lib/mode.ts` `modeMeta` (no badge for default). SessionCard: star toggle, mode badge, branch, compactions.
  - `stores/favorites.ts` (`dirKey` case/sep-insensitive) + `FavoritesList.vue` atop sessions panel (open new / continue / unstar, live count). `connection` `request()` + `toggleFavorite/removeFavorite/openFavorite`.
  - Usage: `stores/usage.ts` `projectRows` (range+model filter only; drive, tokens, models, activeDays, lastDay) + `driveOf`. `usage/ProjectTable.vue` (debounced search with spinner, drive chips, sortable columns w/ aria-sort, page size 25–500 persisted `ccm.projectPageSize`, responsive column hiding) used by full-width `UsageProjects` and `ProjectPickerDialog` (teleported modal, fade+scale, Esc, focus trap/restore, scroll lock) opened from the project filter button.
  - AgentMap re-layouts + fits 240 ms after a panel collapse.
- G2/G3/G4/G7 web:
  - `WaitingQueue.vue` atop MonitorView: waiting sessions sorted by `statusSince`, wait time (≥5 min = alarm style), click → focus map. SessionCard detail shows "waiting for X · 3m 10s".
  - `useNotifications`: kinds waiting/done/reminder/context; `remindersDue` (every 5 min, max 3 per episode keyed id+statusSince, driven by the 1 s `now` clock); context ≥95 % notifies once per crossing (`settings.notifyContext`).
  - `stores/usage.ts` `roots` + `groupRepos` (persisted in `ccm.usage`, default on, toggling clears project filter) → `projectOf` used by `projects`, `filtered`, `byProject`, `projectRows` (`folders` count). ProjectTable "Group by repo" toggle.
- Project table: `table-fixed` + `<colgroup>` widths, drag/arrow-key handles per header (dbl-click resets), density compact/normal/expanded (expanded wraps full path). Picker dialog: bottom-right resize handle (width grows both sides, stays centred), maximize toggle, size persisted.
- SessionList: sort select (`lib/sessionSort.ts`: activity default = `lastActivityAt` desc, started, status, name; ended always last) — sorting is view-only, `terminals.list` order stays stable for the map. "Remove ended (N)" + per-card trash on ended cards → `connection.dismissEnded`.
- Art: `ArtImage.vue` inlines `assets/art/*.svg` (`?raw`) swapping the ember hexes for theme tokens; `LottieArt.vue` lazy-loads `lottie-web/build/player/lottie_light` + JSON, recolours baked colours to tokens at load, reduced-motion → static frame. Used: header logo, sessions empty/loading (radar), usage empty/scanning, project search empty, map empty, favorites launch (check pop), bell on enable. `03-empty-favorites.svg` unused (favorites block hides when empty).
- `AppSelect.vue`: select-only combobox (button `role=combobox` + teleported `role=listbox`, fixed position, flips up, closes on outside/scroll/resize, keys ↑↓ Home End Enter Esc Tab + typeahead; Esc stops propagation so dialogs stay open). Used: session sort, model filter, page size. No native `<select>` left.
- Monitor layout: `MonitorView` sets `grid-template-*` inline from `ui.panelSize` (sessions / activity width, activity height on lg) by breakpoint (matchMedia lg/xl); collapsed = 48px rail. `PanelSplitter.vue` sits absolutely in the gap: drag, arrow keys, dbl-click reset; Agent Map keeps ≥ 360px (`maxFor`). Grid transition disabled while dragging.
- Model chip: `modelLabel` on SessionCard (main) and AgentNode (main + subagents), tooltip = full id. Follows `/model` switches because `Agent.model` is the latest reply model.
- Sprint E–G web: `stores/extras.ts` (jobs, limits, response, modelNames, statusLineCommand, `blockedJobs`). `lib/attention.ts` `quietFor` (working + no transcript line ≥ `settings.stuckMinutes`), `cacheState` (expiry + extra cost via shared `priceOf`), `formatUsd`. `lib/sound.ts` `playChime` (Web Audio). `lib/model.ts` `modelLabel(id, window, names)` + `effortLabel`. - Components: `PlanLimits.vue` in AppHeader (5h/7d bars, 80/95 % levels icon+color, dimmed when report > 30 min old); `JobsList.vue` in sessions panel; `WaitingQueue` lists blocked jobs (non-clickable, "Job" badge); `MetricsStrip` reply-time tile (7 tiles); SessionCard pin button, effort in model chip, quiet line (Hourglass), cache line (Snowflake), Claude-reported cost; AgentNode effort; ActivityFeed sticky "Hide tool calls" + precomputed rows; SettingsMenu stuck threshold radios, sound, status line snippet + copy.
