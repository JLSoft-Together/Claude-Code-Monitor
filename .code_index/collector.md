# collector — apps/collector

Flow: registry dir + projects dir (fs.watch) + reconcile 5s → Monitor → SessionTracker → MonitorStore (diff/batch) → server (ws /ws, static web dist).

- `config.ts` `loadConfig`: CLAUDE_CONFIG_DIR, CCM_PORT (4317), CCM_STALE_TTL_MIN (120), CCM_WEB_DIST, CCM_VERIFY_PROCESSES.
- `registry.ts` `readRegistry`: canonical `<pid>.json` only, whitelisted fields (never socket path / .key), 256KB cap, torn-record retry → `'unreadable'` keeps previous state.
- `process.ts` `isPidAlive`, `queryProcesses` (1 batched PowerShell CIM call: creation FILETIME + parent name), `procStartMatches` (±1ms).
- `tailer.ts` `JsonlTailer`: byte-offset tail, buffer remainder (partial line/utf8), reset on truncate.
- `transcript.ts` `extractSignals` (tool_use/result, usage, model, task-notification tags only, turn_end, end_turn) + `TranscriptState` (open tools, usage map, lastAt).
- `tracker.ts` `SessionTracker`: per terminal (`terminalIdOf` = pid:procStart). Finds transcript (slug guess then scan), discovers `subagents/*.meta.json` (flat dir, nested via `parentAgentId`), `recordLinks` collects Agent tool_use / notifications from main + all subagent transcripts, resolves subagent status after all reads (notification > foreground tool_result > end_turn), `buildTerminal`, `buildAgents`, activity drafts (suppressed in catch-up).
- `monitor.ts` `Monitor`: reconcile (new → verify procStart → catch-up sync; changed → rename/waiting/clear activity; missing/dead → stale; TTL → remove), `verifyLive` 60s, watchers route by sessionId (debounce 150ms).
- `store.ts` `MonitorStore`: maps + activity ring (300), diff → patch, batch flush, seq. Implements `UsageSink` (`resetUsage` / `updateUsage` / `setUsageScan`), usage in snapshot.
- `usage.ts` `UsageIndex`: all `projects/**/*.jsonl` → buckets day×model×cwd×speed (`usageRecordOf` reads counters only). Per-file offset + buckets persisted to `<dataDir>/usage-index.json` (debounced, tmp+rename); first run full scan in background (`usage.scan` progress, then `usage.reset`), then `notify(file)` from projects watcher (1s debounce) + 10 min sweep (batched stat 32, skip same size+mtime) → `usage.updated`. Save: debounce 5 min, immediate after scan, on stop; rename retries EPERM/EBUSY. Ids of files with mtime > 30 days dropped (buckets kept). Dedupe by message.id across all files (`owners` map; resume/fork copies ids). Deleted transcripts keep buckets, release ids; shrunk file recounted.
- `aliases.ts` `AliasStore` + `sanitizeAlias` (≤80 chars, no control chars): dashboard names by terminalId → `<dataDir>/aliases.json`. `Monitor.setAlias` republishes + `terminal.renamed` activity; alias dropped on TTL removal.
- `config.ts` `dataDir` = `CCM_DATA_DIR` || `%LOCALAPPDATA%/ccm`.
- `server.ts` `startServer`: 127.0.0.1, Host local + `isAllowedOrigin` (exact `http://<local>:<port>`, ports = server + `devOriginPorts` from `CCM_DEV_ORIGIN_PORT`/5173), bad URI → 400, stream error → destroy, WS ping 30 s (no pong → terminate), `/health`, `/ws`, static SPA fallback. Client messages validated by shape: `resync`, `terminal.alias`, `favorite.toggle` (terminalId), `favorite.remove` (dir), `favorite.open` (dir, mode new|continue) → `onClientMessage`.
- `transcript.ts` extra signals: `compact` (trigger/pre/post tokens only), `permission_mode`, `branch` (`gitBranch`); `TranscriptState` keeps `contextTokens` (latest usage, reset to postTokens on compact), `peakContext`, `compactions`, `permissionMode`, `gitBranch`. `SessionTracker.sessionActivity` → `terminal.compacted` / `terminal.mode`; `contextOf` → `Agent.contextTokens/contextWindow` via shared `contextWindowOf` + `ContextHints.settingsModel`.
- `claude-settings.ts` `readSettingsModel`: only `model` from `<claudeRoot>/settings.json` (1M window hint), refreshed by `Monitor.refreshHints` at start + every 60 s.
- `favorites.ts` `FavoriteStore` (≤50, key = resolved lower-case path) → `<dataDir>/favorites.json`; `Monitor.toggleFavorite(terminalId)` (dir from tracker cwd, never from client), `removeFavorite`, `openFavorite(dir, mode)` (only stored dirs) → `deps.launch` = `launcher.ts` `launchClaude` (wt.exe new tab, fallback detached powershell; fixed command) → `launch.started` / `launch.failed` activity. Store `setFavorites` → `favorites.updated`, snapshot `favorites`.
- `index.ts`: wires AliasStore → Monitor (`onProjectFile` → `UsageIndex.notify`), server, then `usage.start()`; shutdown awaits `usage.stop()` (final save).
- Tests: `test/units.test.ts`, `test/monitor.test.ts` (fixture claude root, fake deps, alias), `test/usage.test.ts` (parse, pricing, scan/tail/partial line/cache restore/truncate).
- `repo.ts` `RepoRoots.resolve(dir)`: nearest `.git` ancestor (stat only, cached per dir, stops below home/drive root). Wired in `index.ts` via `store.onNewProjects` → `store.setProjectRoots` (emits `usage.roots` with new entries; snapshot `usage.roots`). `tracker.buildTerminal` adds `statusSince` (registry `statusUpdatedAt`, live only).
- `Monitor.dismissEnded(terminalId?)` → `forget(tracker)` (same path as stale-TTL removal: trackers, store `removeTerminal` + agents, alias). Never touches live trackers.
- Sprint E–G: `transcript.ts` signals carry `effort` (model) and `ttl`/`at` (usage) → `TranscriptState.effort/cacheTtl/cacheAt` → `Agent.effort/cacheTtl/cacheAt`. `jobs.ts` `JobReader` (whitelist `parseJobState`, `lastStateChange` from timeline tail), `model-catalog.ts` `readModelNames`, `statusline.ts` `StatusLineReader` + `latestLimits` (files from `scripts/statusline-bridge.mjs`), `response.ts` `ResponseTracker` (today's waiting→busy durations, persisted). `Monitor.pollExtras` (every reconcileMs): jobs (+ `job.blocked`/`job.done` activity on change), limits, per-session `costUsd`, day roll. Response recorded in `applyRecordChange`. Store: `setJobs/setLimits/setResponse/setModelNames`, `statusLineCommand` (from `config.statusLineBridge`), separate `toolActivity` ring (snapshot merges by time). Tests `test/extras.test.ts`.
- `Monitor.addFavorite(dir, label)`: strips quotes, rejects relative/UNC (`\\host` would hit SMB) and non-dirs → `store.rejectFavorite`; `FavoriteStore.add` → ok|exists|limit. Activity rings 1000 each (`config.activityLimit`).
- Sprint H: `forecast.ts` `LimitHistory.apply` (samples per window, least squares → forecast; `<dataDir>/limit-history.json`), `history.ts` `SessionHistory` (`endTracker` → `recordOf` → `history.added`), `timeline.ts` `StatusTimeline.observe` (every publish; totals feed history), `json-file.ts` debounced atomic JSON. `focus.ts` raise window by pid. Monitor ctor takes `MonitorStores {limitHistory, history, timeline}`. server: cache `no-cache` outside `/assets/`, `.webmanifest` MIME.
