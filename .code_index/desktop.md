# desktop — apps/desktop (Electron, Windows + macOS)

Flow: `main.ts` `ready()` → `CollectorHost.start()` (fork collector; port already healthy → fatal `port-in-use`) → BrowserWindow loads `http://127.0.0.1:<port>/`. Plan `.planning/PLAN-v12-electron.md`, docs §11j.

## Files
- `src/main.ts`: single-instance lock, AUMID `dev.ccm.monitor`, `lockPermissions` (notifications/clipboard/fullscreen, app origin only), `harden` (deny window.open → `openAppWindow` for app URLs / `shell.openExternal` http(s); block cross-origin navigate; F5/Ctrl R, F12, zoom keys), main window (bounds in `userData/window.json`, close = hide + one balloon), compact window (`?mode=compact`, 440×720), tray menu (open / compact / Start with Windows `--hidden` / logs / quit), `boot()` loading page → host.start → load ORIGIN, `before-quit` → `host.stop()`.
- Dev HMR (`npm run desktop:dev` = Vite + `electron stage --dev-url=http://127.0.0.1:5173`): `DEV_URL` (ignored when packaged, loopback http only) → `PAGE_ORIGIN`; `isAppUrl` accepts ORIGIN + PAGE_ORIGIN, `boot()` waits for Vite (30 s) then loads PAGE_ORIGIN, `sendAppKey` also tags requests to the Vite origin (its proxy forwards `x-ccm-app` on `/ws`), pty `origins` + collector `CCM_DEV_ORIGIN_PORT` include it. Vite `strictPort` so the origin never drifts. Main/collector changes still need a restart.
- `src/collector-host.ts` `CollectorHost`: `isHealthy` (`GET /health`); a healthy port before fork = another collector (old .bat / npm start) → `FatalError('port-in-use')`, never borrowed (it would receive the app key); `utilityProcess.fork(collector.cjs)` stdout/stderr → `logs/collector.log` + 40-line `tail`; `stop()` posts `'shutdown'`, kill after 4 s.
- `src/bridge.ts` `installBridge`: copy bridge → `<dataDir>/bin/statusline-bridge.mjs` (write if changed); command `node "<script>"` if portable/dev or `node` on PATH, else Windows `statusline-bridge.cmd` / mac+linux `statusline-bridge.sh` (chmod 755) running the exe with `ELECTRON_RUN_AS_NODE=1`.
- `src/pages.ts`: loading / error `data:` pages (tokens match launcher page), retry link `ccm-desktop://retry` intercepted in `will-navigate` → `boot()`.
- `src/strings.ts`: en/vi by `app.getLocale()` (+ `trayLoginMac`, `move*`).
- `src/mac.ts`: `adoptLoginShellPath` (`$SHELL -ilc` PATH merge, launchd PATH is minimal), `setMacMenu` (app/edit/window roles), `offerMoveToApplications` (true → relaunching, `ready()` returns). `main.ts` `IS_MAC`: tray `ccmTrayTemplate.png`, no window icon / AUMID / balloon, `activate` → `showMain`, login item `{}`.
- Name: product **Agent Monitor** (was Claude Code Monitor, 2026-10-11); `appId`/AUMID `dev.ccm.monitor`, data dir `ccm` unchanged so updates install in place. `repairLoginItem` re-points a login entry still aimed at the old `Claude Code Monitor.exe` (same folder) to the new exe.
- `build.mjs`: esbuild → `stage/main.cjs` (external electron) + `stage/collector.cjs` (from `apps/collector/src/index.ts`), writes `stage/package.json` without dependencies.
- `electron-builder.yml`: app dir `stage`, output `release`; win nsis + portable x64 unsigned; mac dmg arm64 + x64, icon `scripts/assets/ccm-mac.png`, ad-hoc `identity: '-'`, `hardenedRuntime: false`. All dist scripts `--publish never`.
- root `npm run dist` → `scripts/dist.mjs` picks `dist:win` / `dist:mac` by `process.platform` (node-pty extraResource is host-only, so no cross builds).
- `.github/workflows/desktop.yml`: manual / tag `v*` → `dist:mac` on macos-latest + `dist:win` on windows-latest → upload artifacts.
- Icons: source `scripts/assets/logo.svg` (also `web/src/assets/art/01-logo.svg`, `web/public/favicon.svg`); `scripts/make-icon.mjs` mirrors its geometry (`shapes()`: fill/ring/line SDF) and `render(size, {inset, radius, glyph})` → `ccm.ico` + `ccm-256.png` + PWA icons (full-bleed), `ccm-mac.png` (1024, inset 100, radius 230 — only rounded tile, macOS does not mask), `ccmTrayTemplate{,@2x}.png` (16/32 black glyph, strokes ×1.6, cropped to frame). Edit the SVG → update `shapes()` → rerun.

## Invariants
- Window must load the **http origin**, never `file://`: `server.ts` origin check accepts only http localhost; web builds WS URL from `location.host`.
- Collector bundle is CJS: `config.ts` `import.meta` fallbacks only run when `CCM_WEB_DIST` / `CCM_STATUSLINE_BRIDGE` are unset → host must always set both.
- Fatal/restart: exit code 3 (`PORT_IN_USE_EXIT`, mirrors collector `server.ts`) → `FatalReason` `port-in-use`, no restart, `strings.ts` `portInUse(port)`. Other child exit while not stopping → restart up to 3 times; then `onFatal` → error page with log tail + retry. Boot waits `/health` up to 30 s (timeout → fatal). Retry = `boot()` → `start()` resets restart count.
- Quit only via tray (`window-all-closed` no-op); `before-quit` waits `host.stop()` once (`stopped` flag).
- Desktop only (v2.0.0, `.planning/PLAN-v19-desktop-only.md`): `sendAppKey` adds `X-CCM-App: <APP_KEY>` via `session.webRequest.onBeforeSendHeaders` to `ORIGIN/*` + `ws://127.0.0.1:<port>/*`; the collector 403s anything else (browsers). Toast links: `registerLinks` (packaged win, `setAsDefaultProtocolClient(agent-monitor, PORTABLE_EXE ?? execPath)`), `linkIn(argv)` on first launch + `second-instance` → `openLink`: snooze → `collectorFetch(/snooze?…)`; focus → `paneHandles` (IPC `ccm:focus` → page answers `ccm:focus-reply` within 1.5 s; pane → show app) → else POST `/focus` → not `ok` → show app + `ccm:select` (Monitor, select session). E2E `e2e/desktop-only.cjs`.
- `src/attention.ts` `createAttention(dock)` (macOS only, `main.ts` sets `CCM_TOAST_BACKEND=electron`): collector `toast.show|hide` via `CollectorHost` `onMessage` → new tag bounces dock (critical), badge = `badgeCount`; `browser-window-focus` → `settle()` (cancel bounces, drop non-persistent tags); `before-quit` → `clear()`.
- `CollectorHost` `onMessage` feeds `attention.handle`; `onExit` (child exit, before respawn/fatal) → `attention.clear()` so the badge never outlives the collector.

## Embedded terminals (v18 P1, `.planning/PLAN-v18-terminal-workspace.md`)
- `src/pty/host.ts` → `stage/pty-host.cjs` (utilityProcess, asarUnpack): node-pty required by path `CCM_NODE_PTY` (packaged `resources/pty/node_modules/@lydell/node-pty`, extraResources copies `node_modules/@lydell` incl. the platform prebuilt; dev = repo `node_modules`). WS `127.0.0.1:<random>/pty`: Host must be 127.0.0.1, Origin in `CCM_PTY_ORIGINS` (app origin only), token in `Sec-WebSocket-Protocol` `ccm.pty.<hex>` (`timingSafeEqual`). Text frames = `PtyClientMessage`/`PtyServerMessage` (`packages/shared/src/pty.ts`), binary = I/O. Spawn only fixed presets (`src/pty/presets.ts`: win `powershell -NoLogo [-NoExit -Command <agent>]`, posix `$SHELL -l -i -c '<agent>; exec $SHELL -l'`), cwd absolute existing dir (default home), max 16. 256 KB ring per session replayed on `attach` (reload); 8 ms flush; pause PTY when `ws.bufferedAmount` > 512 KB, resume < 128 KB; exit = flush → `exit`; kill = `taskkill /T /F` on Windows + `proc.kill()`. Child env strips `CCM_*`. parentPort: `census` → live sessions, `shutdown` → kill all + `process.exit` (ConPTY keeps loop alive).
- `src/pty/supervisor.ts` `PtySupervisor`: lazy fork on first `endpoint()`, fresh 32-byte token per fork, `logs/pty.log`, `census()`, `stop()`.
- P2: `src/pty/owners.ts` `readPidTable` (win PowerShell CIM `ProcessId ParentProcessId` rows / `/bin/ps -A -o pid= -o ppid=`), `ownersOf` (walk ppid ≤32 to a live session's shell pid). Host `owners` message (≤64 pids, table cached 1.5 s for a burst). IPC `ccm:pick-folder` → `dialog.showOpenDialog` openDirectory (same frame check), preload `pickFolder()`.
- `presets.ts` `childEnv` also strips `AGENT_SESSION_VARS` (CLAUDECODE, CLAUDE_CODE_CHILD_SESSION / SESSION_ID / MESSAGING_TOKEN…, CODEX_THREAD_ID…): an app started from inside a Claude session otherwise makes pane agents "child sessions" (no transcript / registry → no link) and leaks the parent's messaging token.
- P4: `src/pty/git.ts` (`findGit` own PATH walk — libuv would try the project cwd first; `runGit` = `git -C <cwd>` with GIT_TERMINAL_PROMPT=0 / GIT_OPTIONAL_LOCKS=0 / LC_ALL=C; `parseWorktrees` porcelain, first = main; `isBranchName` conservative ref rules, no leading dash; `worktreeDest` `<repo>-wt/<branch / → ->`; `branchOfHead`). Host: per session `trackBranch` (rev-parse --absolute-git-dir → fs.watch git dir for HEAD, debounce 120 ms → `branch` msg, re-sent on attach); `wt.list|add|remove` (one mutation at a time; add = existing branch checkout or `-b`, args end with `--`; remove refuses main / dirty (`status --porcelain`) / any live session cwd inside, never `--force`; prunable → `worktree prune`). Tests `apps/desktop/test/pty.test.ts` (vitest, `npm test -w @ccm/desktop`).
- P7: `@lydell/node-pty` is a devDependency on purpose (electron-builder would otherwise pack it into app.asar too; runtime uses `resources/pty` from extraResources). CI `desktop.yml` mac job installs both `@lydell/node-pty-darwin-{x64,arm64}` (--no-save --force) so each dmg has its prebuilt. mac menu Close has `registerAccelerator:false` (page owns Cmd+W). E2E: `apps/desktop/e2e/` (`npm run e2e -w @ccm/desktop [packaged exe]`, CDP driver `cdp.cjs`: own port 4399, temp profile + data dir, occlusion off; scripts p2–p6 + csp; output/screenshots in `%TEMP%/ccm-e2e`).
- `src/preload.ts` → `stage/preload.cjs` (sandboxed, every window): `window.ccmDesktop = { platform, ptyEndpoint(), pickFolder(), logs(), onFocus(), onSelect() }` → IPC `ccm:pty-endpoint`; main answers only top-level frames whose URL is the app origin.
- Quit: `before-quit` → `confirmQuit()` (census; dialog lists `preset — ~/cwd`, default Cancel) → stop collector + PTY host. `session-end` skips the dialog. Permission `clipboard-read` allowed (app origin) for image-aware Ctrl+V.
- Hardening (P1 security review): endpoint IPC also requires `CollectorHost.ownsPort` (only while our collector child runs); Origin allowlist = app origin only; presets use absolute `%SystemRoot%\…\powershell.exe` / validated `$SHELL`, `taskkill.exe` absolute; `childEnv` strips `CCM_*`, `ELECTRON_*`, `NODE_OPTIONS` (case-insensitive); cwd rejects UNC + `realpath`; host survives bad frames (`uncaughtException` log, ws `error` handlers, try/catch around spawn/resize/write); `kill {id}` from a throwaway socket; exited sessions pruned after 30 min detached; cap counts live only; watchdog exits if Electron parent dies; ring = one string trimmed at 1.5× cap. Quit: `confirmQuit` asks even if census times out (null), `allSettled` + 8 s `app.exit` deadline, `session-end` skips dialog.
- 2.0.0: IPC `ccm:logs` (`copy` | `save`, top-level app frame only): `logReport` = app/Electron/OS + port ownership + page diagnostics + tail 256 KB of `collector.log` / `pty.log`, opaque runs ≥32 chars masked; save → Downloads `agent-monitor-log-<stamp>.txt` + reveal.
- v20 audit A: `log-mask.ts` `maskLog` (sk-/gh*_/github_pat_/AKIA/xox*, opaque runs ≥32 incl. base64 / . -, home → ~ (win32: case-insensitive, `\`, `/` and JSON `\\` separators); runs starting with / stay) used by `logReport`; `ccm:logs` save write failure → `{ok:false}`; `openLink` focus needs non-empty `k`.
