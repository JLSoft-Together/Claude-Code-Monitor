# forest-cabin — art direction

**Mood:** cosy timber lodge at dusk — log walls, wool plaid, ferns and a stone hearth, lit by candle-warm lamps.

**Materials:** dark pine plank floors and log walls, cream wool, wool red plaid rugs and cushions, fern green
upholstery and plants, grey stone hearth, brass lamp light.

**Key colours:** dark pine `#5b3d2a`, wool red `#b4473a`, fern `#4f7d4a`, stone `#9a9488`, candle `#f1c46b`,
cream wool `#efe3c8`, deep forest `#2f4a3a`.

**Light:** top-left; dusk feel only through warm colour (orange sky, candle-yellow pools), no cast shadows.

**Outline:** `#2b3245` (upstream, kept so posters and procedural sprites share one outline).

## Subjects

Paintings: pine ridge (landscape), teapot (still life), red fox (animal), mushrooms (nature), wool plaid
(pattern), snowy cabin (night scene), night owl (animal), hill village (town). Wide: canoe lake, starry peaks,
patchwork quilt (abstract). Posters: code window on cream, red camp mug, cream rocket on forest green, ginger cat,
crossed-out beetle, red sailboat for ship-it. Empty office: log lodge with stone fireplace lounge, green sofa,
plaid rugs, wooden desk islands with glowing monitors, shelves, water cooler, coffee counter, pine forest windows.

## Picks

All first takes except: village (take 2, simpler three-house composition), rocket (take 2, cream body instead of
red-on-green clutter), code (take 3, dark window on cream reads better than on dark pine / fern), ship-it (take 3,
sailboat — the cargo-ship takes reduced to unreadable colour blocks at 12×16), teapot (replaces the lantern).

## Rejected

- `painting-lantern` takes 1–2: lantern became a brown/yellow blob at 26×16.
- `painting-candle` take 1: flame and wax merged into one yellow keyhole shape. Slot reused as `painting-teapot`.
- `poster-code` takes 1–2, `poster-rocket` take 1, `poster-ship-it` takes 1–2, `painting-village` take 1.

## Weak but kept

- `painting-snow-cabin`: busy at native size, cabin small; reads as snowy night scene.
- `poster-bug`: beetle and red ring merge a little; still reads as "no bug".

Requests: 27 / 40 (all logged in `generation-log.json`).
