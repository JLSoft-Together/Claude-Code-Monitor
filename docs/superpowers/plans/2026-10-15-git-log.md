# Git Log Pane (v30) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only, IntelliJ-style Git Log pane in the Workspace: branch/tag tree, commit list with a multi-lane graph and filters, the selected commit's files and details, and a diff of any file in that commit.

**Architecture:** The Electron main process runs plain `git` commands (`for-each-ref`, `log`, `show`, `diff-tree`, `branch --contains`, `diff`) through the existing `execGit` and returns raw rows over IPC (`ccm:log-*`), reusing the repo registration of the Changes pane. The page computes graph lanes incrementally (`lib/commitGraph.ts`), builds the ref tree and pill labels (`lib/gitRefs.ts`), maps filters to a query (`lib/logQuery.ts`) and keeps state in `composables/useGitLog.ts`. `LogPane.vue` is a new Workspace pane kind `log`, one per repo, like `changes`.

**Tech Stack:** Electron 3x main (Node, TypeScript), Vue 3 + Pinia + vue-i18n + Tailwind v4, Vitest, CDP E2E scripts (`apps/desktop/e2e/*.cjs`).

**Spec:** `docs/superpowers/specs/2026-10-15-git-log-design.md`

## Global Constraints

- **Read-only.** No git command that writes: no checkout, branch, reset, cherry-pick, revert, fetch, pull, push, stash. Copy actions only.
- Every page-supplied string reaches git only after `=` or `--`, never as its own argument. Hashes match `^[0-9a-f]{4,40}$` (case-insensitive) and are verified with `rev-parse --verify -q <hash>^{commit}`. Branch refs match `^refs/(heads|remotes|tags)/…` or `HEAD`. Paths go through `safeRepoPath`.
- Page size `LOG_PAGE = 500`; graph lanes drawn at most `MAX_LANES = 30` (wider lanes are drawn in the last column).
- Graph shown when no filter or only the Branch filter is set; flat list (dots only) when User / Date / Text / Paths is set.
- All UI strings via vue-i18n in `apps/web/src/i18n/workspace-log.ts` (en + vi), merged into `workspace.log`.
- Colours via theme tokens only (`.planning/COLOR-SYSTEM.md`): local ref pill `accent` fill / `accent-ink` text, remote `ink-muted`, tag `warning`, file kinds `diff-*` via `KIND_CLASS`. **Lane colours use `model-1..8`** (the categorical dataviz series). The spec said `agent-*`, but COLOR-SYSTEM reserves `agent-*` for agent kinds, so this plan corrects it.
- Status = icon + text + colour, never colour alone. No horizontal page scroll: long text truncates with a `title` tooltip.
- Content surfaces opaque; blur (`ccm-menu`) only on popovers.
- Before UI tasks (9–13) load skills `frontend-design:frontend-design` and `ui-ux-pro-max:ui-ux-pro-max` (CLAUDE.md rule).
- Write files with LF line endings. Keep comments sparse and "why"-only, like the surrounding code.
- Entry points: Changes pane toolbar, Explorer › Changes header, Ctrl+K, and the `+` new-tab menu (`LaunchPicker`). `TermPane` has no context menu today, so the spec's "terminal context menu" becomes the `+` menu entry. This is a deviation from the spec.
- Commit messages: gitmoji, English, imperative, no `Co-Authored-By` line (owner's rule).
- Version 2.5.0 (`apps/desktop/package.json`).

```ts
export const LOG_PAGE = 500

export type LogError = 'denied' | 'no-git' | 'not-repo' | 'failed' | 'missing'

/** `ref` = full refname (`refs/heads/main`), `name` = short (`main`, `origin/main`, `v1.0`). */
export interface LogRef {
  ref: string
  name: string
  hash: string
}

export interface LocalRef extends LogRef {
  upstream: string | null
  ahead: number
  behind: number
  /** Upstream branch was deleted on the remote. */
  gone: boolean
}

export interface RemoteGroup {
  name: string
  refs: LogRef[]
}

export type RefsResult =
  | { ok: true; root: string; head: { branch: string | null; hash: string | null }; local: LocalRef[]; remotes: RemoteGroup[]; tags: LogRef[]; me: string | null }
  | { ok: false; error: LogError }

export interface LogCommit {
  hash: string
  parents: string[]
  author: string
  email: string
  /** Author time, epoch seconds. */
  time: number
  /** Raw `%D` decorations: `HEAD -> main, origin/main, tag: v1`. */
  refs: string
  subject: string
}

export interface LogQuery {
  /** Full refname or `HEAD`; null = every branch, remote and tag. */
  branch: string | null
  author: string | null
  since: number | null
  until: number | null
  text: string | null
  regex: boolean
  matchCase: boolean
  /** Repo-relative, `/` separators. */
  paths: string[]
  skip: number
}

export type LogPageResult = { ok: true; commits: LogCommit[]; more: boolean } | { ok: false; error: LogError }

export type CommitFileKind = 'added' | 'modified' | 'deleted' | 'renamed' | 'copied' | 'typechange'

export interface CommitFile {
  path: string
  origPath?: string
  kind: CommitFileKind
  added?: number
  removed?: number
  binary?: boolean
}

export type CommitDetail =
  | {
      ok: true
      hash: string
      parents: string[]
      author: string
      email: string
      authorTime: number
      committer: string
      committerEmail: string
      commitTime: number
      message: string
      /** Compared with the first parent (empty tree for a root commit). */
      files: CommitFile[]
      truncated: boolean
    }
  | { ok: false; error: LogError }

export type ContainsResult = { ok: true; branches: string[] } | { ok: false; error: LogError }

export const isHash = (v: unknown): v is string => typeof v === 'string' && /^[0-9a-f]{4,40}$/i.test(v)
```

```ts
import path from 'node:path'
import { LOG_PAGE, type CommitFile, type CommitFileKind, type LocalRef, type LogCommit, type LogQuery, type LogRef, type RemoteGroup } from '@ccm/shared'
import { safeRepoPath } from './changes'

export const FS = '\x1f'
export const LOG_FORMAT = ['%H', '%P', '%an', '%ae', '%at', '%D', '%s'].join('%x1f')
export const MAX_COMMIT_FILES = 5000
const MAX_PATHS = 20
const REF = /^refs\/(heads|remotes|tags)\/[^\s~^:?*[\\]+$/

export function parseLog(out: string): LogCommit[] {
  const commits: LogCommit[] = []
  for (const rec of out.split('\0')) {
    const f = rec.replace(/^\n/, '').split(FS)
    if (f.length < 7 || !f[0]) continue
    commits.push({ hash: f[0], parents: f[1] ? f[1].split(' ') : [], author: f[2]!, email: f[3]!, time: Number(f[4]) || 0, refs: f[5]!, subject: f.slice(6).join(FS) })
  }
  return commits
}

export function parseTrack(s: string): { ahead: number; behind: number; gone: boolean } {
  if (s.trim() === 'gone') return { ahead: 0, behind: 0, gone: true }
  return { ahead: Number(/ahead (\d+)/.exec(s)?.[1] ?? 0), behind: Number(/behind (\d+)/.exec(s)?.[1] ?? 0), gone: false }
}

/** `for-each-ref --format=%(refname)%1f%(objectname)%1f%(*objectname)%1f%(upstream:short)%1f%(upstream:track,nobracket)`. */
export function parseRefLines(out: string, remotes: string[]): { local: LocalRef[]; remotes: RemoteGroup[]; tags: LogRef[] } {
  const local: LocalRef[] = []
  const tags: LogRef[] = []
  const groups = new Map<string, LogRef[]>()
  // Longest first: a remote named `my/fork` must win over `my`.
  const names = [...remotes].sort((a, b) => b.length - a.length)
  for (const line of out.split('\n')) {
    const [ref, obj, peeled, upstream, track] = line.split(FS)
    if (!ref || !obj) continue
    const hash = peeled || obj
    if (ref.startsWith('refs/heads/')) local.push({ ref, name: ref.slice(11), hash, upstream: upstream || null, ...parseTrack(track ?? '') })
    else if (ref.startsWith('refs/tags/')) tags.push({ ref, name: ref.slice(10), hash })
    else if (ref.startsWith('refs/remotes/')) {
      const short = ref.slice(13)
      if (short.endsWith('/HEAD')) continue
      const remote = names.find((n) => short.startsWith(`${n}/`)) ?? short.split('/')[0]!
      const list = groups.get(remote) ?? []
      list.push({ ref, name: short, hash })
      groups.set(remote, list)
    }
  }
  const sorted = [...groups.keys()].sort((a, b) => a.localeCompare(b))
  return { local, remotes: sorted.map((name) => ({ name, refs: groups.get(name)! })), tags }
}

const KIND: Record<string, CommitFileKind> = { A: 'added', M: 'modified', D: 'deleted', R: 'renamed', C: 'copied', T: 'typechange' }

/** `diff-tree -r -z -M --name-status`: `X\0path\0`, renames / copies `R087\0old\0new\0`. */
export function parseNameStatus(out: string): CommitFile[] {
  const parts = out.split('\0')
  const files: CommitFile[] = []
  for (let i = 0; i < parts.length; ) {
    const status = parts[i++]
    if (!status) continue
    const kind = KIND[status[0]!] ?? 'modified'
    if (kind === 'renamed' || kind === 'copied') {
      const origPath = parts[i++]!
      const p = parts[i++]
      if (p) files.push({ path: p, origPath, kind })
    } else {
      const p = parts[i++]
      if (p) files.push({ path: p, kind })
    }
  }
  return files
}

const str = (v: unknown, max = 500): string | null => (typeof v === 'string' && v.trim() ? v.trim().slice(0, max) : null)
const epoch = (v: unknown): number | null => (typeof v === 'number' && Number.isFinite(v) && v > 0 ? Math.floor(v) : null)

export function cleanLogQuery(raw: unknown, root: string): LogQuery {
  const o = (raw && typeof raw === 'object' ? raw : {}) as Record<string, unknown>
  const branch = typeof o.branch === 'string' && (o.branch === 'HEAD' || (REF.test(o.branch) && !o.branch.includes('..') && !o.branch.endsWith('.lock'))) ? o.branch : null
  const paths = (Array.isArray(o.paths) ? o.paths : [])
    .map((p) => safeRepoPath(root, p)?.rel)
    .filter((p): p is string => !!p)
    .slice(0, MAX_PATHS)
  const skip = typeof o.skip === 'number' && Number.isFinite(o.skip) && o.skip > 0 ? Math.min(Math.floor(o.skip), 10_000_000) : 0
  return { branch, author: str(o.author, 200), since: epoch(o.since), until: epoch(o.until), text: str(o.text), regex: o.regex === true, matchCase: o.matchCase === true, paths, skip }
}

const escapeRegex = (s: string): string => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
const iso = (s: number): string => new Date(s * 1000).toISOString()

/** `git log` args; one extra row tells whether another page exists. */
export function logArgs(q: LogQuery): string[] {
  const args = ['log', '--topo-order', '-z', `--format=${LOG_FORMAT}`, `--skip=${q.skip}`, '-n', String(LOG_PAGE + 1)]
  if (q.author) args.push(`--author=${q.regex ? escapeRegex(q.author) : q.author}`)
  if (q.since) args.push(`--since=${iso(q.since)}`)
  if (q.until) args.push(`--until=${iso(q.until)}`)
  if (q.text) args.push(`--grep=${q.text}`)
  if (q.text || q.author) {
    args.push(q.regex ? '--extended-regexp' : '--fixed-strings')
    if (!q.matchCase) args.push('--regexp-ignore-case')
  }
  args.push(...(q.branch ? [q.branch] : ['--branches', '--remotes', '--tags', 'HEAD']), '--', ...q.paths)
  return args
}
```

```ts
async function resolveCommit(root: string, hash: unknown): Promise<string | LogError> {
  if (!isHash(hash)) return 'denied'
  const res = await execGit(root, ['rev-parse', '--verify', '-q', `${hash}^{commit}`], { maxBytes: 4096 })
  return res.code === 0 ? res.stdout.trim() : 'missing'
}

export async function logPage(root: string, rawQuery: unknown): Promise<LogPageResult> {
  const q = cleanLogQuery(rawQuery, root)
  const hasHead = (await execGit(root, ['rev-parse', '-q', '--verify', 'HEAD'], { maxBytes: 4096 })).code === 0
  if (!hasHead && !q.branch) return { ok: true, commits: [], more: false }
  const res = await execGit(root, logArgs(q), T)
  if (res.code !== 0 && !res.truncated) return { ok: false, error: fail(res) }
  let commits = parseLog(res.stdout)
  const more = commits.length > LOG_PAGE || res.truncated
  commits = commits.slice(0, LOG_PAGE)
  // A hash typed in the text field: that commit first, then the message matches.
  if (q.skip === 0 && q.text && isHash(q.text)) {
    const full = await resolveCommit(root, q.text)
    if (full !== 'denied' && full !== 'missing') {
      const one = await execGit(root, ['log', '-z', `--format=${LOG_FORMAT}`, '-n', '1', full, '--'], T)
      const found = one.code === 0 ? parseLog(one.stdout)[0] : undefined
      if (found) commits = [found, ...commits.filter((c) => c.hash !== found.hash)]
    }
  }
  return { ok: true, commits, more }
}

export async function commitDetail(root: string, hash: unknown): Promise<CommitDetail> {
  const full = await resolveCommit(root, hash)
  if (full === 'denied' || full === 'missing') return { ok: false, error: full }
  const show = await execGit(root, ['show', '-s', `--format=${['%H', '%P', '%an', '%ae', '%at', '%cn', '%ce', '%ct', '%B'].join('%x1f')}`, full], T)
  if (show.code !== 0) return { ok: false, error: fail(show) }
  const f = show.stdout.split(FS)
  const parents = f[1] ? f[1].split(' ') : []
  const base = await parentOf(root, parents)
  if (!base) return { ok: false, error: 'failed' }
  const [names, nums] = await Promise.all([
    execGit(root, ['diff-tree', '-r', '-z', '-M', '--name-status', base, full], T),
    execGit(root, ['diff-tree', '-r', '-z', '-M', '--numstat', base, full], T),
  ])

export async function commitDiff(root: string, hash: unknown, rel: unknown, optsInput?: unknown, origRel?: unknown): Promise<ChangesDiff> {
  const safe = safeRepoPath(root, rel)
  const orig = origRel === undefined ? null : safeRepoPath(root, origRel)
  if (!safe || (origRel !== undefined && !orig)) return { ok: false, error: 'denied' }
  const full = await resolveCommit(root, hash)
  if (full === 'denied' || full === 'missing') return { ok: false, error: full }
  const parents = (await execGit(root, ['rev-list', '--parents', '-n', '1', full], { maxBytes: 16_384 })).stdout.trim().split(' ').slice(1)
  const base = await parentOf(root, parents)
  if (!base) return { ok: false, error: 'failed' }

  const paths = orig ? [orig.rel, safe.rel] : [safe.rel]
  const runDiff = (o: Required<DiffOptions>, maxBytes: number) => execGit(root, ['diff', base, full, '-M', '--no-ext-diff', '--no-textconv', ...diffArgs(o), '--', ...paths], { maxBytes, timeoutMs: 20_000 })
  let res = await runDiff(opts, opts.context === 'full' ? MAX_FULL_DIFF_BYTES : MAX_DIFF_BYTES)
  let partial = false

    partial = true
    res = await runDiff({ ...opts, context: 3 }, MAX_DIFF_BYTES)
  }

}
```

```ts
// IntelliJ-style lanes over `git log --topo-order` rows. Lanes keep their column; freed columns are reused.
export interface CommitLink {
  hash: string
  parents: readonly string[]
}

/** One half-row segment: `top` = row top → node height, `bottom` = node height → row bottom. */
export interface GraphEdge {
  from: number
  to: number
  color: number
  half: 'top' | 'bottom'
}

export interface GraphRow {
  lane: number
  color: number
  edges: GraphEdge[]
  width: number
}

/** `lanes[i]` = hash the lane waits for (null = free column). */
export interface GraphState {
  lanes: (string | null)[]
  colors: number[]
  next: number
}

export const MAX_LANES = 30
export const emptyGraph = (): GraphState => ({ lanes: [], colors: [], next: 0 })
export const clampLane = (i: number): number => Math.min(i, MAX_LANES - 1)
export const flatRows = (n: number): GraphRow[] => Array.from({ length: n }, () => ({ lane: 0, color: 0, edges: [], width: 1 }))
export const graphWidth = (rows: readonly GraphRow[]): number => rows.reduce((w, r) => Math.max(w, r.width), 1)

const freeSlot = (lanes: (string | null)[]): number => {
  const i = lanes.indexOf(null)
  return i < 0 ? lanes.length : i
}

export function extendGraph(state: GraphState, commits: readonly CommitLink[]): { state: GraphState; rows: GraphRow[] } {
  const lanes = [...state.lanes]
  const colors = [...state.colors]
  let next = state.next
  const rows: GraphRow[] = []
  for (const commit of commits) {
    const edges: GraphEdge[] = []
    let lane = lanes.indexOf(commit.hash)
    for (let i = 0; i < lanes.length; i++) {
      if (lanes[i] === null) continue
      edges.push({ from: i, to: lanes[i] === commit.hash ? lane : i, color: colors[i]!, half: 'top' })
    }
    if (lane < 0) {
      lane = freeSlot(lanes)
      colors[lane] = next++
    }
    const color = colors[lane]!
    for (let i = 0; i < lanes.length; i++) if (lanes[i] === commit.hash) lanes[i] = null
    const [first, ...rest] = commit.parents
    const touched = new Set<number>()
    if (first !== undefined) {
      lanes[lane] = first
      edges.push({ from: lane, to: lane, color, half: 'bottom' })
      touched.add(lane)
    } else lanes[lane] = null
    for (const parent of rest) {
      let j = lanes.indexOf(parent)
      if (j < 0) {
        j = freeSlot(lanes)
        lanes[j] = parent
        colors[j] = next++
        touched.add(j)
      }
      edges.push({ from: lane, to: j, color: colors[j]!, half: 'bottom' })
    }
    for (let i = 0; i < lanes.length; i++) if (lanes[i] !== null && !touched.has(i)) edges.push({ from: i, to: i, color: colors[i]!, half: 'bottom' })
    while (lanes.length && lanes[lanes.length - 1] === null) {
      lanes.pop()
      colors.pop()
    }
    const width = edges.reduce((w, e) => Math.max(w, e.from + 1, e.to + 1), lane + 1)
    rows.push({ lane, color, edges, width })
  }
  return { state: { lanes, colors, next }, rows }
}
```

Note on edge order (what the tests pin): top edges by lane, then the node's own bottom, then merge bottoms, then pass-through bottoms by lane. A lane already waiting for a merge parent keeps its pass-through bottom edge, because it is not in `touched`.

```ts
import type { RefsResult } from '@ccm/shared'

export interface RefLabel {
  kind: 'head' | 'local' | 'remote' | 'tag'
  name: string
  current?: boolean
  /** Set on a local label whose `<remote>/<name>` points at the same commit (shown as "origin & main"). */
  remote?: string
}

export type RefsOk = Extract<RefsResult, { ok: true }>

export function parseDecorations(d: string, remotes: readonly string[]): RefLabel[] {
  const parts = d.split(', ').map((s) => s.trim()).filter(Boolean)
  const labels: RefLabel[] = []
  const remoteNames = new Set<string>()
  for (const p of parts) {
    if (p === 'HEAD') labels.push({ kind: 'head', name: 'HEAD', current: true })
    else if (p.startsWith('HEAD -> ')) labels.push({ kind: 'local', name: p.slice(8), current: true })
    else if (p.startsWith('tag: ')) labels.push({ kind: 'tag', name: p.slice(5) })
    else if (remotes.some((r) => p.startsWith(`${r}/`))) {
      if (!p.endsWith('/HEAD')) remoteNames.add(p)
    } else labels.push({ kind: 'local', name: p })
  }
  for (const l of labels) {
    if (l.kind !== 'local') continue
    const r = remotes.find((rem) => remoteNames.has(`${rem}/${l.name}`))
    if (r) {
      l.remote = r
      remoteNames.delete(`${r}/${l.name}`)
    }
  }
  const tagsAt = labels.findIndex((l) => l.kind === 'tag')
  const remoteLabels: RefLabel[] = [...remoteNames].map((name) => ({ kind: 'remote', name }))
  if (tagsAt < 0) return [...labels, ...remoteLabels]
  return [...labels.slice(0, tagsAt), ...remoteLabels, ...labels.slice(tagsAt)]
}

export const labelText = (l: RefLabel): string => (l.remote ? `${l.remote} & ${l.name}` : l.name)

export type RefRow =
  | { kind: 'section'; id: string; section: 'head' | 'local' | 'remote' | 'tags'; depth: 0; expanded: boolean }
  | { kind: 'folder'; id: string; name: string; depth: number; expanded: boolean }
  | {
      kind: 'ref'
      id: string
      ref: string
      name: string
      leaf: string
      depth: number
      refKind: 'head' | 'local' | 'remote' | 'tag'
      current: boolean
      tracked: boolean
      ahead: number
      behind: number
      gone: boolean
    }

interface Leaf {
  ref: string
  name: string
  refKind: 'local' | 'remote' | 'tag'
  current: boolean
  tracked: boolean
  ahead: number
  behind: number
  gone: boolean
}

/** Rows of `leaves` nested by `/` under `prefix`; `strip` = leading name part already shown by a parent row. */
function nest(rows: RefRow[], leaves: Leaf[], idBase: string, depth: number, strip: string, collapsed: ReadonlySet<string>, open: boolean): void {
  const folders = new Map<string, Leaf[]>()
  const direct: Leaf[] = []
  for (const l of leaves) {
    const rest = l.name.slice(strip.length)
    const slash = rest.indexOf('/')
    if (slash < 0) direct.push(l)
    else {
      const f = rest.slice(0, slash)
      folders.set(f, [...(folders.get(f) ?? []), l])
    }
  }
  for (const l of direct) {
    const leaf = l.name.slice(strip.length)
    rows.push({ kind: 'ref', id: `r:${l.ref}`, ref: l.ref, name: l.name, leaf, depth, refKind: l.refKind, current: l.current, tracked: l.tracked, ahead: l.ahead, behind: l.behind, gone: l.gone })
  }
  for (const [f, list] of folders) {
    const id = `${idBase}/${f}`
    const expanded = open || !collapsed.has(id)
    rows.push({ kind: 'folder', id, name: f, depth, expanded })
    if (expanded) nest(rows, list, id, depth + 1, `${strip}${f}/`, collapsed, open)
  }
}

export function refTree(refs: RefsOk, filter: string, collapsed: ReadonlySet<string>): RefRow[] {
  const q = filter.trim().toLowerCase()
  const match = (name: string): boolean => !q || name.toLowerCase().includes(q)
  const filtering = !!q
  const rows: RefRow[] = [{ kind: 'section', id: 'head', section: 'head', depth: 0, expanded: true }]
  const local: Leaf[] = refs.local
    .filter((l) => match(l.name))
    .map((l) => ({ ref: l.ref, name: l.name, refKind: 'local', current: l.name === refs.head.branch, tracked: !!l.upstream, ahead: l.ahead, behind: l.behind, gone: l.gone }))
  const section = (id: 'local' | 'remote' | 'tags', leaves: Leaf[] | null, fill: () => void): void => {
    if (filtering && leaves !== null && !leaves.length) return
    const expanded = filtering || !collapsed.has(id)
    rows.push({ kind: 'section', id, section: id, depth: 0, expanded })
    if (expanded) fill()
  }
  section('local', local, () => nest(rows, local, 'local', 1, '', collapsed, filtering))
  const remoteLeaves = refs.remotes.map((g) => ({
    name: g.name,
    leaves: g.refs.filter((r) => match(r.name)).map<Leaf>((r) => ({ ref: r.ref, name: r.name, refKind: 'remote', current: false, tracked: false, ahead: 0, behind: 0, gone: false })),
  }))
  section('remote', remoteLeaves.flatMap((g) => g.leaves), () => {
    for (const g of remoteLeaves) {
      if (filtering && !g.leaves.length) continue
      const id = `remote/${g.name}`
      const expanded = filtering || !collapsed.has(id)
      rows.push({ kind: 'folder', id, name: g.name, depth: 1, expanded })
      if (expanded) nest(rows, g.leaves, id, 2, `${g.name}/`, collapsed, filtering)
    }
  })
  const tags: Leaf[] = refs.tags.filter((t) => match(t.name)).map((t) => ({ ref: t.ref, name: t.name, refKind: 'tag', current: false, tracked: false, ahead: 0, behind: 0, gone: false }))
  section('tags', tags, () => nest(rows, tags, 'tags', 1, '', collapsed, true))
  return rows
}
```

```ts
import type { LogQuery } from '@ccm/shared'

export type DatePreset = 'any' | '24h' | '7d' | '30d' | 'custom'
export const DATE_PRESETS: DatePreset[] = ['any', '24h', '7d', '30d', 'custom']

export interface LogFilters {
  text: string
  regex: boolean
  matchCase: boolean
  /** Full refname or null (all). */
  branch: string | null
  author: string | null
  date: DatePreset
  /** `YYYY-MM-DD`, local time, for `custom`. */
  from: string
  to: string
  /** Repo-relative. */
  paths: string[]
}

export const emptyFilters = (): LogFilters => ({ text: '', regex: false, matchCase: false, branch: null, author: null, date: 'any', from: '', to: '', paths: [] })

const DAY = 86400
const SPAN: Record<'24h' | '7d' | '30d', number> = { '24h': DAY, '7d': 7 * DAY, '30d': 30 * DAY }

function day(s: string): number | null {
  const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(s)
  if (!m) return null
  const t = new Date(Number(m[1]), Number(m[2]) - 1, Number(m[3])).getTime()
  return Number.isFinite(t) ? t / 1000 : null
}

export function toQuery(f: LogFilters, now: number, skip = 0): LogQuery {
  let since: number | null = null
  let until: number | null = null
  if (f.date === 'custom') {
    since = day(f.from)
    const end = day(f.to)
    until = end === null ? null : end + DAY - 1
  } else if (f.date !== 'any') since = Math.floor(now / 1000) - SPAN[f.date]
  const text = f.text.trim()
  return { branch: f.branch, author: f.author, since, until, text: text || null, regex: f.regex, matchCase: f.matchCase, paths: [...f.paths], skip }
}

/** IntelliJ keeps the graph only while the history stays connected (no filter, or a branch). */
export const graphMode = (f: LogFilters): 'graph' | 'flat' => (f.author || f.text.trim() || f.paths.length || f.date !== 'any' ? 'flat' : 'graph')

export const hasFilters = (f: LogFilters): boolean => !!(f.branch || f.author || f.text.trim() || f.paths.length || f.date !== 'any')
```

```ts
import { computed, onScopeDispose, ref, shallowRef, watch, type ComputedRef, type Ref, type ShallowRef } from 'vue'
import type { CommitDetail, LogCommit, LogError } from '@ccm/shared'
import { emptyGraph, extendGraph, flatRows, type GraphRow, type GraphState } from '../lib/commitGraph'
import { samePath } from '../lib/changesView'
import type { RefsOk } from '../lib/gitRefs'
import { emptyFilters, graphMode, toQuery, type LogFilters } from '../lib/logQuery'
import { changesUnwatch, changesWatch, logCommit, logContains, logPage, logRefs, onChangesUpdated } from '../lib/preview'

export type LogLoadError = LogError | 'unavailable'

export interface GitLog {
  root: Ref<string | null>
  refs: ShallowRef<RefsOk | null>
  error: Ref<LogLoadError | null>
  filters: Ref<LogFilters>
  commits: ShallowRef<LogCommit[]>
  rows: ShallowRef<GraphRow[]>
  mode: ComputedRef<'graph' | 'flat'>
  more: Ref<boolean>
  loading: Ref<boolean>
  loadingMore: Ref<boolean>
  selected: Ref<string | null>
  detail: ShallowRef<CommitDetail | null>
  detailLoading: Ref<boolean>
  authors: ComputedRef<string[]>
  reload(): Promise<void>
  loadMore(): Promise<void>
  select(hash: string | null): void
  setFilters(patch: Partial<LogFilters>): void
  contains(hash: string): Promise<string[] | null>
  refreshIfMoved(): Promise<void>
}

const DETAIL_CACHE = 50

/** HEAD + every ref hash: unchanged after a file save, changed by a commit / fetch / checkout. */
export const refsSignature = (r: RefsOk): string =>
  JSON.stringify([r.head, r.local.map((l) => [l.ref, l.hash, l.ahead, l.behind]), r.remotes.map((g) => g.refs.map((x) => [x.ref, x.hash])), r.tags.map((t) => [t.ref, t.hash])])

export function useGitLog(cwd: () => string, active: () => boolean, opts: { debounceMs?: number; now?: () => number } = {}): GitLog {
  const debounceMs = opts.debounceMs ?? 250
  const now = opts.now ?? Date.now
  const root = ref<string | null>(null)
  const refs = shallowRef<RefsOk | null>(null)
  const error = ref<LogLoadError | null>(null)
  const filters = ref<LogFilters>(emptyFilters())
  const commits = shallowRef<LogCommit[]>([])
  const rows = shallowRef<GraphRow[]>([])
  const mode = computed(() => graphMode(filters.value))
  const more = ref(false)
  const loading = ref(true)
  const loadingMore = ref(false)
  const selected = ref<string | null>(null)
  const detail = shallowRef<CommitDetail | null>(null)
  const detailLoading = ref(false)
  const cache = new Map<string, CommitDetail>()
  let graph: GraphState = emptyGraph()
  let seq = 0
  let detailSeq = 0
  let signature = ''
  let watched: string | null = null
  let timer: ReturnType<typeof setTimeout> | null = null

  const authors = computed(() => {
    const names = new Set<string>()
    for (const c of commits.value) names.add(c.author)
    return [...names].sort((a, b) => a.localeCompare(b))
  })

  function applyPage(list: LogCommit[], append: boolean): void {
    if (mode.value === 'graph') {
      const next = extendGraph(append ? graph : emptyGraph(), list)
      graph = next.state
      rows.value = append ? [...rows.value, ...next.rows] : next.rows
    } else {
      graph = emptyGraph()
      rows.value = append ? [...rows.value, ...flatRows(list.length)] : flatRows(list.length)
    }
    commits.value = append ? [...commits.value, ...list] : list
  }

  async function loadRefs(): Promise<boolean> {
    const res = await logRefs(root.value ?? cwd())
    if (!res.ok) {
      error.value = res.error
      refs.value = null
      return false
    }
    refs.value = res
    signature = refsSignature(res)
    if (root.value !== res.root) {
      root.value = res.root
      void watchRoot(res.root)
    }
    return true
  }

  async function firstPage(): Promise<void> {
    const run = ++seq
    const r = root.value
    if (!r) return
    loading.value = true
    const res = await logPage(r, toQuery(filters.value, now(), 0))
    if (run !== seq) return
    loading.value = false
    if (!res.ok) {
      error.value = res.error
      applyPage([], false)
      more.value = false
      return
    }
    error.value = null
    applyPage(res.commits, false)
    more.value = res.more
    if (selected.value && !res.commits.some((c) => c.hash === selected.value)) select(res.commits[0]?.hash ?? null)
    else if (!selected.value) select(res.commits[0]?.hash ?? null)
  }

  async function reload(): Promise<void> {
    if (await loadRefs()) await firstPage()
    else loading.value = false
  }

  async function loadMore(): Promise<void> {
    const r = root.value
    if (!r || !more.value || loadingMore.value || loading.value) return
    const run = seq
    loadingMore.value = true
    const res = await logPage(r, toQuery(filters.value, now(), commits.value.length))
    loadingMore.value = false
    if (run !== seq || !res.ok) return
    applyPage(res.commits, true)
    more.value = res.more
  }

  function select(hash: string | null): void {
    selected.value = hash
    const run = ++detailSeq
    if (!hash || !root.value) {
      detail.value = null
      return
    }
    const hit = cache.get(hash)
    if (hit) {
      cache.delete(hash)
      cache.set(hash, hit)
      detail.value = hit
      return
    }
    detailLoading.value = true
    void logCommit(root.value, hash).then((res) => {
      if (run !== detailSeq) return
      detailLoading.value = false
      if (res.ok || res.error !== 'unavailable') {
        const d = res as CommitDetail
        if (d.ok) {
          cache.set(hash, d)
          if (cache.size > DETAIL_CACHE) cache.delete(cache.keys().next().value!)
        }
        detail.value = d
      }
    })
  }

  function setFilters(patch: Partial<LogFilters>): void {
    filters.value = { ...filters.value, ...patch }
  }

  watch(
    filters,
    () => {
      if (timer) clearTimeout(timer)
      seq++
      timer = setTimeout(() => {
        timer = null
        void firstPage()
      }, debounceMs)
    },
    { deep: true },
  )

  async function contains(hash: string): Promise<string[] | null> {
    if (!root.value) return null
    const res = await logContains(root.value, hash)
    return res.ok ? res.branches : null
  }

  async function refreshIfMoved(): Promise<void> {
    const before = signature
    if (!(await loadRefs())) return
    if (signature !== before) {
      cache.clear()
      await firstPage()
    }
  }

  async function watchRoot(r: string): Promise<void> {
    if (watched === r) return
    if (watched) void changesUnwatch(watched)
    watched = r
    await changesWatch(r)
  }

  const off = onChangesUpdated(({ root: changed }) => {
    if (root.value && active() && samePath(changed, root.value)) void refreshIfMoved()
  })

  watch(active, (on) => {
    if (on) void refreshIfMoved()
  })
  watch(cwd, () => {
    root.value = null
    cache.clear()
    void reload()
  })

  onScopeDispose(() => {
    off()
    if (timer) clearTimeout(timer)
    if (watched) void changesUnwatch(watched)
  })

  void reload()

  return { root, refs, error, filters, commits, rows, mode, more, loading, loadingMore, selected, detail, detailLoading, authors, reload, loadMore, select, setFilters, contains, refreshIfMoved }
}
```

```vue
import { computed } from 'vue'
import { clampLane, MAX_LANES, type GraphRow } from '../../../lib/commitGraph'

const props = defineProps<{ row: GraphRow; lanes: number; head?: boolean }>()
const LANE = 12
const H = 24
const PAD = 8
const x = (i: number): number => PAD + clampLane(i) * LANE
const colour = (c: number): string => `var(--ccm-model-${(c % 8) + 1})`
const width = computed(() => PAD * 2 + (Math.min(props.lanes, MAX_LANES) - 1) * LANE)
const paths = computed(() =>
  props.row.edges.map((e) => {
    const y0 = e.half === 'top' ? 0 : H / 2
    const y1 = e.half === 'top' ? H / 2 : H
    const x0 = x(e.from)
    const x1 = x(e.to)
    const mid = (y0 + y1) / 2
    return { d: x0 === x1 ? `M${x0} ${y0}V${y1}` : `M${x0} ${y0}C${x0} ${mid} ${x1} ${mid} ${x1} ${y1}`, stroke: colour(e.color) }
  }),
)
</script>
```

```vue
const emit = defineEmits<{ pick: [id: string] }>()

function pick(id: string): void {
  emit('pick', id)
  open.value = false
  button.value?.focus()
}

function onKey(e: KeyboardEvent): void {
  if (e.key === 'Escape') {
    e.preventDefault()
    e.stopPropagation()
    open.value = false
    button.value?.focus()
    return
  }
  if (e.key !== 'ArrowDown' && e.key !== 'ArrowUp') return
  e.preventDefault()
  const items = [...(menu.value?.querySelectorAll<HTMLElement>('[role^="menuitem"]') ?? [])]
  const at = items.indexOf(document.activeElement as HTMLElement)
  items[(at + (e.key === 'ArrowDown' ? 1 : -1) + items.length) % items.length]?.focus()
}

function onPointerDown(e: PointerEvent): void {
  const target = e.target as Node
  if (open.value && !menu.value?.contains(target) && !button.value?.contains(target)) open.value = false
}

onBeforeUnmount(() => document.removeEventListener('pointerdown', onPointerDown, true))

watch(open, (v) => {
```

```ts
import type { DiffWhitespace } from './preview'

export interface DiffOpts {
  layout: 'inline' | 'split'
  collapse: boolean
  context: number
  whitespace: DiffWhitespace
  words: boolean
}

export const DIFF_OPTS_KEY = 'ccm.workspace.diffOpts'
const OLD_LAYOUT_KEY = 'ccm.workspace.diffLayout'
export const CONTEXTS = [3, 5, 10]
export const WHITESPACE: DiffWhitespace[] = ['none', 'eol', 'all', 'all-blank']

function read(key: string): string | null {
  try {
    return localStorage.getItem(key)
  } catch {
    return null
  }
}

/** Shared by the Changes and Log diff viewers. */
export function readDiffOpts(): DiffOpts {
  const base: DiffOpts = { layout: read(OLD_LAYOUT_KEY) === 'split' ? 'split' : 'inline', collapse: true, context: 3, whitespace: 'none', words: true }
  try {
    const raw = JSON.parse(read(DIFF_OPTS_KEY) ?? 'null') as Partial<DiffOpts> | null
    if (!raw || typeof raw !== 'object') return base
    return {
      layout: raw.layout === 'split' ? 'split' : raw.layout === 'inline' ? 'inline' : base.layout,
      collapse: typeof raw.collapse === 'boolean' ? raw.collapse : base.collapse,
      context: CONTEXTS.includes(raw.context as number) ? (raw.context as number) : base.context,
      whitespace: WHITESPACE.includes(raw.whitespace as DiffWhitespace) ? (raw.whitespace as DiffWhitespace) : base.whitespace,
      words: typeof raw.words === 'boolean' ? raw.words : base.words,
    }
  } catch {
    return base
  }
}

export function writeDiffOpts(o: DiffOpts): void {
  try {
    localStorage.setItem(DIFF_OPTS_KEY, JSON.stringify(o))
  } catch {
    // private mode / quota: options last for this session only
  }
}
```

  ```md
  ## 11s. Git Log pane reads history with plain git (v30, desktop only, read-only, 2026-10-15)

  Not monitoring: an IntelliJ-style log of a project's repo. Every command is read-only and runs through `execGit` (`GIT_LITERAL_PATHSPECS=1`, no colour, no pager).
  ```
